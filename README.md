# Лабораторная работа № 8

Реализовать сервис диалогов между пользователями социальной сети на основе примера:

* Добавить авторизацию пользователей аналогично Лаб. 6;
* Выводить имя и иконку пользователя из бд;
* Реализовать ОДИН групповой чат между всеми пользователями;
* Сохранять чаты после отключения пользователей не требуется.
* На доп баллы реализовать механизм Групп аналогичный [примеру](https://github.com/microsoft/SignalR-Samples-AI):
  * Есть несколько чатов между которыми пользователи могут переключаться;
   * Сообщения приходят в один концентратор и распределяются по группам.
